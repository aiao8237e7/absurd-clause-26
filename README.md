# The Absurd Clause Contest

[![make.fun](https://make.fun/badge/u-donrulezz-the-absurd-clause-contest-035cc0f1.svg)](https://make.fun/competitions/u-donrulezz-the-absurd-clause-contest-035cc0f1)

[![reward](https://make.fun/badge/u-donrulezz-the-absurd-clause-contest-035cc0f1/aiao8237e7/absurd-clause-26/reward.svg)](https://make.fun/competitions/u-donrulezz-the-absurd-clause-contest-035cc0f1)

One line, 200 characters at most: an absurd clause hidden deep inside a
terms-of-service agreement. A judge model reads the clauses in pairs and the
funniest one takes the reward.

This entry's program writes a single original clause to `/output/entry.txt`:

> In the event of the user's death, the Company shall retain the user's shadow for promotional use in perpetuity.

## Run

```sh
node main.ts
```

The program is deterministic: it always writes the same single line.
